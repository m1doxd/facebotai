How it works

AI PIPELINE

One photo is sent to the FaceBot Gemini Worker, which validates the upload, analyzes the visible face and returns structured JSON.

01
Photo upload

The Mini App validates JPG, PNG and WEBP files up to 15 MB.

02
Gemini analysis

The Worker sends the image to the configured Gemini model using the server-side API key.

03
Structured result

The Worker normalizes the score, metrics and feature groups into a stable API response.

04
Face Report

The Mini App renders the returned values and saves a compact history locally.
