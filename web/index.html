Методология

MEASUREMENT FIRST

Система разделяет объективные измерения и качественную интерпретацию. Gemini может описывать уже полученные результаты, но не придумывает числовые измерения и не меняет score.

01
Visible features

Видимые особенности лица используются для оценки пропорций, отношений и других визуальных параметров.

02
Geometry

Параметры рассчитываются из фактически полученных координат и измерений.

03
Symmetry

Левая и правая стороны сравниваются относительно выбранной центральной оси.

04
Gemini

Используется для текстовой интерпретации уже полученных измерительных данных.

05
No fabricated score

Интерфейс не создаёт случайный score. Если сервер не вернул валидное числовое значение, результат не показывается.

GEMINI / BYOK

Подключи Gemini API

Для анализа фотографии нужен твой Gemini API ключ. Он сохраняется только в localStorage этого браузера и передаётся Worker через X-Gemini-Key.

Как получить ключ:
1. Открой Google AI Studio
2. Создай API Key
3. Скопируй его сюда
4. Нажми «Подключить и сохранить»
Ключ не хранится в app.js или Worker-коде. Не вставляй его в публичный код проекта.
