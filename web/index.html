О системе

SUB5 / LOCAL DEMO

Минималистичный интерфейс для локального анализа изображения. Здесь намеренно нет регистрации, серверной загрузки фотографии или выдачи псевдонаучного «объективного» рейтинга человека.

01
Фото остаётся в браузере

Изображение читается через File API и используется только для демонстрационного расчёта.

02
Метрики — визуальные

Яркость, контраст, пропорции и центрирование относятся к самому кадру, а не к ценности человека.

03
Интерфейс без перегруза

Тёмная тема, плавные переходы, раскрывающиеся детали и нижняя навигация сохраняют стиль твоего исходного CSS.
